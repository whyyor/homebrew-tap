# whyyor/homebrew-tap

Homebrew formulas for [tuimessenger](https://github.com/whyyor/tuimessenger) — WhatsApp, Telegram, Slack and
Instagram in one terminal app.

```sh
brew install whyyor/tap/tuimessenger
```

Works on macOS (Apple silicon and Intel) and Linux (x86_64 and arm64) with Homebrew.

`Formula/tuimessenger.rb` is written by tuimessenger's release workflow for every release; don't edit it here.
